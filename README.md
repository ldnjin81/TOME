# TOME

**Track, Own, Merge, Explore — a desktop client for Lore.**

[한국어](README.ko.md)

TOME is a community desktop client for [Lore](https://github.com/EpicGames/lore), the version control system by Epic Games. It talks to Lore in-process through Lore's C API, so it never parses command-line output.

> **Status:** early (0.1). Works day to day against a Lore 0.10 server; Windows is the main platform.

## What it does

- **Track** — a Smartlog of your stack: your unpushed revisions against the server, the full graph of every branch, revision and file diffs, and the history of a single file.
- **Own** — the team's locks on one board, lock and unlock from any file or asset, and live notices when someone locks, unlocks or pushes.
- **Merge** — create, switch and merge branches and settle conflicts file by file. Restack by drag and drop: move your stack onto new server revisions, or reorder it, with a preview of the files that may conflict, binary files whose side you choose up front, and locks held by others.
- **Explore** — edit the View and apply it right away (files leaving and coming back). An **artist mode** browses the working copy's Unreal assets with the thumbnails saved in each `.uasset`, and marks what is changed, conflicted or locked.

Also: P4V-style custom tools on files and revisions, long operations (clone, sync, push) with progress and cancel, and the Lore command line for each action in the status bar.

## Install (Windows)

- **Installer** — `TOME_<version>_x64-setup.exe` installs for the current user (no administrator rights). It installs the WebView2 runtime if Windows does not have it.
- **Portable** — unzip `TOME_<version>_x64_portable.zip` and run `tome.exe`. It needs the WebView2 runtime, which Windows 11 includes.

Settings are kept in `%APPDATA%\dev.ldnjin.tome`.

## Build from source

```sh
git clone --recursive <this repository>
cd TOME/ui && npm ci && cd ..
cargo test -p tome-core            # server tests are opt-in: TOME_TEST_SERVER=lore://host:port
ui/node_modules/.bin/tauri build   # or scripts\package-windows.ps1 for the installer and zip
```

Lore is built from the `third_party/lore` submodule and linked in.
